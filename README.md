# Where to submit your startup

Find places that still accept startup submissions — and see what you actually get.
Free vs paid. Users, backlinks, or both.
Every listing includes a submission link and a last-checked date.

First batch of entries reviewed 2026-09-24.

## How to read the list

**Free?** refers to the listing, not whether the product being submitted has a free plan. Any required payment, reciprocal link, or paid upgrade should be disclosed.

**Last checked** is the date a contributor reviewed the submission route and listing terms, in `YYYY-MM-DD` format. Weekly automated checks test link availability; they do not refresh this date or prove that submissions are accepted.

## Add or update a directory

Edit the tables above and open a pull request. Read [CONTRIBUTING.md](CONTRIBUTING.md) for the row template and verification checklist.

Found a broken link or changed price? [Report it](https://github.com/mmmmingos/where-to-submit-your-startup/issues/new/choose) with a source and the date you checked.

## Maintenance

[Link checks](https://github.com/mmmmingos/where-to-submit-your-startup/actions/workflows/links.yml) run every Monday, on README/contribution-guide changes, and on demand. Each run provides a report in its summary and downloadable artifacts. A failed check needs review: a login wall or bot block does not necessarily mean the directory is dead. Known bot-wall hosts are listed in [`lychee.toml`](lychee.toml) with the date they were investigated.
